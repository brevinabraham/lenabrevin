OUR FOREVER — WEDDING WEBSITE (V28)

1. Open index.html from this folder.
2. Replace photos in images/ with files of the same name:
   welcome-portrait.jpg, engagement-photo.jpg, wedding-photo.jpg,
   header-thumbnail.jpg.
3. For guest portraits use images/guests/first-last.jpg; for the couple,
   images/guests/you.jpg and images/guests/partner.jpg.
4. Add guests in the Guest Directory and enter parents/partners for family links.
5. The family tree keeps couples together and uses aligned, right-angle
   relationship lines. It rearranges automatically when relatives are added.
6. Guest data is local to the browser; use Download Backup to preserve it.
   The website is a demonstration and does not share uploads online yet.
